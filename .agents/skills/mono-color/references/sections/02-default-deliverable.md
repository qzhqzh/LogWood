## Default Deliverable

Create:

1. one final image-generation prompt;
2. one generated raster image;
3. a short recipe note naming palette, layout family, type pairing, and print process.

When a persistent file path is available, save generated files under `artifacts/mono-color/` in the current project unless the user supplies another workspace-local path. Create the folder if needed. Do not write outside the current workspace unless the user explicitly requests it. Stop at prompt-only only when the user explicitly asks for it or no image-generation capability is available.
